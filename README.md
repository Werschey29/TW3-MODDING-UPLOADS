Here you find older versions of my Warhammer Total War 3 Mods I released in the Workshop. 
The versions are before major updates of the mods, so you can go back if you have issues with the newer ones.

How to install? 
Download the .pack file and put it into the 'Steam\steamapps\common\Total War WARHAMMER III\data' folder. 
Then launch the game via the "TW Mod Manager (early access)" and select the respective mod that is labled "Game Dir" uncheck the steam version of the mod if it appears there.
